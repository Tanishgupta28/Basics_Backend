## About

This repository contains my hands-on practice and learning notes while exploring JavaScript and backend development.

The goal is to strengthen my programming fundamentals and gradually build scalable backend applications.

## Topics Covered

### JavaScript
- Variables, Data Types, and Operators
- Arrays, Objects, and Functions
- Scope, Closures, and Hoisting
- DOM Manipulation and Events
- Object-Oriented Programming
- Promises, Async/Await, and APIs

### Backend Development
- Node.js Fundamentals
- NPM and Modules
- Express.js and Routing
- Middleware and Error Handling
- EJS Templating
- Environment Variables
